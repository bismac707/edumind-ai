EduMind AI – Student Success & Learning Analytics

EduMind AI is an interactive educational analytics platform designed to explore student performance, identify learners who may need additional support, and generate data-driven learning insights.

Key Features

- Interactive student performance dashboard
- Student explorer with learner profiles
- Machine Learning model using Logistic Regression
- Model evaluation using Accuracy, Precision, Recall and F1-score
- Confusion matrix and model coefficients
- Student intervention recommendations
- Dataset preview and CSV functionality
- Responsive dark-themed interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Machine Learning – Logistic Regression

Machine Learning

The application uses synthetic student data and a Logistic Regression model to estimate which learners may benefit from additional academic support.

Project Purpose

This project demonstrates how data science and machine learning can support educational decision-making and student performance analysis.

Important Note

This is an educational portfolio prototype. It uses synthetic data, and its predictions are not diagnoses or validated real-world assessments. Human review is essential.
